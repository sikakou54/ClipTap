■ What is ClipTap

ClipTap is a simple iOS app for copying text templates with one tap.

Register frequently used texts and copy instantly. Use variables like {{today}}, {{name}} to auto-insert information.

Intuitive UI that improves productivity.


■ Ideal for

・Email and social media users
・Frequent address/phone entry
・Templates with dates and times
・Programmers and engineers
・Customer support staff
・Sales representatives
・Writers and bloggers


■ Key Features

【One-Tap Copy】
Tap to copy. Confirmed with haptic feedback.

【System Variables (Free)】
{{today}}, {{now}}, {{year}}, {{month}}, {{day}}, {{weekday}} available. Auto-insert dates.

【Profile Management (Pro)】
Create multiple profiles to switch variable values by context. Free: 3 profiles. Pro: unlimited. Create "Company A" and "Company B" profiles to auto-switch {{company}} values.

【Custom Variables (Pro)】
Variables like {{name}}, {{email}}, {{company}}. Free: 5 variables. Pro: unlimited. Register once, auto-replace everywhere.

【Ad-Free (Pro)】
Zero ads. Perfect for focused work.

【Category Management】
Organize with categories. Set icons and colors.

【Fast Search】
Search by keyword. Find text instantly.

【Fully Offline】
Works without internet. Data stays on iPhone.

【Privacy Focused】
All data local, no cloud sync.

【Dark Mode】
Auto-follows iOS settings.

【Multi-Language】
Japanese and English.

■ How to Use

【STEP 1】Register
Tap + to add text. Include variables like {{today}}.

【STEP 2】Set Variables (Optional)
Pro users create custom variables in Settings.

【STEP 3】Organize
Create categories.

【STEP 4】Copy
Tap template. Variables convert and copy.

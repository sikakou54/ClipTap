■ What is ClipTap?

ClipTap is a clipboard manager app that lets you copy frequently used text snippets with just one tap.
From email templates to code snippets, store any text and access it instantly.
Features like auto-expanding variables and a custom keyboard extension make repetitive typing a thing of the past.

■ How to Use (4 Steps)

【STEP 1】Register Templates
Tap the plus button to register frequently used text.
You can include variables like {{today}} or {{name}} in the content.

【STEP 2】Set Variables (Optional)
System variables work automatically, but Pro plan users can create custom variables.
Register {{name}}, {{email}}, etc. from the Settings screen.

【STEP 3】Organize by Category
As templates increase, create categories to organize them.
Classifying by usage makes them easier to find later.

【STEP 4】Tap to Copy
Just tap the template you want to use, and variables automatically convert to actual values and copy to clipboard.

2. Set Variables: Define {{name}} as "John Doe" in Settings.
3. Tap & Copy: Tap the snippet, and "Best regards, John Doe" is copied!
4. Keyboard: Enable ClipTap keyboard in iOS Settings to type directly in other apps.

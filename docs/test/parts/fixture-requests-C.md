## 1. `sortable` の修正 — 対応済み

**依頼した内容**

`sortable.sql` は「4種の並べ替えで順序が全て変わる」と書かれていたが、実データは
作成日時＝使用頻度（D,C,B,A）、更新日時＝タイトル（AAA〜DDD）となっており、
**2組しか区別できなかった。**

**対応後のデータ**

```
sn_a AAA created 2026-02-01 updated 2026-03-03 copyCount 10
sn_b BBB created 2026-02-02 updated 2026-03-04 copyCount  5
sn_c CCC created 2026-02-03 updated 2026-03-01 copyCount 30
sn_d DDD created 2026-02-04 updated 2026-03-02 copyCount 20
```

| 並べ替え | 期待順序 |
|---|---|
| タイトル（昇順） | AAA, BBB, CCC, DDD |
| 作成日時（新しい順） | DDD, CCC, BBB, AAA |
| 更新日時（新しい順） | BBB, AAA, DDD, CCC |
| 使用頻度（多い順） | CCC, DDD, AAA, BBB |

4種すべてが異なる順序になったため、`sortable` 単体で並べ替えを一意に切り分けられる。

**テスト仕様書への反映**

- 期待値を更新: TC-2301（更新日時）、TC-2303（使用頻度）
- 期待値そのまま（新データでも一致）: TC-2300、TC-2302、TC-2008、TC-2314、TC-2315、TC-2122
- **暫定回避だった `baseline` 併用の4テストを削除**: TC-2304 / TC-2305 / TC-2306 / TC-2307
  と、対応するパターン P-F09-005 〜 P-F09-008 を削除した（PatternIDに欠番が生じている）。
  `baseline` でのタイトル昇順・作成日時順は、NULLタイトルの位置を検証する
  TC-2311 / TC-2312 が引き続きカバーする。

## 3. `profile-limited-category` の追加 — 対応済み

`cat_only_a`（A社専用）の定型文が `A社用` にだけ紐づき、アクティブは `Main`。

**統括からの問い合わせへの回答（期待値は機能仕様書から導いた）**

§8.8 は「モバイルホームは『すべて』と、**そのプロファイルで定型文が存在する個別カテゴリだけ**を表示し」
と定めている。`Main` では `cat_only_a` に属する定型文が1件も表示対象にならないため、
**仕様上「A社専用」チップは表示されない。** したがって
「チップを選んだ結果0件になる」という状態は**仕様上そもそも成立しない**。

実装（`useHomeScreen` が `filterCategoriesWithSnippets` へ渡すのはプロファイル絞り込み後の
`allSnippets`）も同じ結論になるため、**仕様と実装の食い違いは無い。**
両方をパターンとして残す必要は生じなかった。

- `P-F08-007` を `UNREACHABLE` → `REACHABLE` に変更し、内容を
  「カテゴリ絞り込みで0件になる」から**「アクティブプロファイルに定型文が無いカテゴリはチップに現れない」**へ
  書き換えたうえで、**TC-2213** を新規作成。
- 併せて `ConditionID` を `C-F08-01`（チップの選択）から `C-F08-02`（チップに現れる範囲）へ移した。

## 4. `duplicate-title` の追加 — 対応済み

同一タイトル `同名` 2件（`sn_same_old` 2026-02-01 / `sn_same_new` 2026-02-09）＋ `ZZZ` 1件。

- `P-F09-012` を `UNREACHABLE` → `REACHABLE` に変更し、**TC-2324** を新規作成。
- 検証内容: タイトル昇順で `ZZZ, 同名, 同名` の順に並ぶこと（`ZZZ` の `Z`=0x5A が
  `同`=U+540C より前）と、本文の並び（`別タイトルの本文。` → `新しい方の本文。` → `古い方の本文。`）で
  同名2件のうち**作成日時の新しい方が上**に来ることを確認する。

- `P-F07-018`（絵文字を検索語として入力）を `UNREACHABLE` → `REACHABLE` に変更し、
  **TC-2131** を新規作成（`fixture=boundary`、`TYPE_PASTE` で `🎯` を貼り付け）。

- 他の入力はすべてBMP内（日本語・ASCII・`{{}}`・`<>`・`%`・`_`）のため `TYPE` のままとした。

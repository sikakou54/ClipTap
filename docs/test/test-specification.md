## 凡例

### 種別

| 種別 | 説明 |
|------|------|
| N | 正常系（Normal） |
| E | 異常系（Error） |
| B | 境界値（Boundary） |
| A | 代替フロー（Alternative） |

### 優先度

| 優先度 | 説明 |
|--------|------|
| P1 | 必須（リリースブロッカー） |
| P2 | 重要（主要機能） |
| P3 | 通常（補助機能） |

### データパターンID参照

入力値/選択値カラムでは、[use-cases-data-patterns.md](./use-cases-data-patterns.md) のパターンIDを参照します。

| 接頭辞 | 意味 | 例 |
|--------|------|-----|
| DP-IN | 入力値パターン | DP-IN-SNP-03（スニペットタイトル通常値） |
| DP-SEL | 選択値パターン | DP-SEL-COL-01（Blue色） |
| DP-BND | 境界値パターン | DP-BND-CHR-01（タイトル最大30文字） |
| DP-SYS | システム変数 | DP-SYS-01（today変数） |
| DP-SPEC | 特殊文字 | DP-SPEC-01（絵文字） |

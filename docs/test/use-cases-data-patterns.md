## 概要

本ドキュメントは、ClipTapアプリケーションで使用される入力値、選択値、および境界値のデータパターンを定義します。テストケース作成時のデータ設計に使用してください。

### パターンID命名規則

| 接頭辞 | 意味 |
|--------|------|
| DP-IN | 入力値パターン (Input) |
| DP-SEL | 選択値パターン (Selection) |
| DP-BND | 境界値パターン (Boundary) |
| DP-SYS | システム変数パターン (System) |
| DP-DT | 日時パターン (DateTime) |
| DP-ID | ID形式パターン (Identifier) |
| DP-ERR | エラーコードパターン (Error) |
| DP-BOOL | ブール値パターン (Boolean) |
| DP-EVT | イベントパターン (Event) |
| DP-SPEC | 特殊文字パターン (Special) |

### 統計

| 項目 | 数値 |
|-----|------|
| 総パターン数 | 約180件 |
| 入力値パターン | 9カテゴリ |
| 選択値パターン | 6カテゴリ |
| 対応ユースケース | 87件 |
